# TokenUsage Logo Assets

- `tokenusage-logomark.svg`: square icon mark (app icon / avatar style).
- `tokenusage-logo-horizontal.svg`: horizontal lockup for README and social headers.

Notes:
- Both are SVG (infinite scale, easy recolor/export).
- Font fallback stack in SVG: `Audiowide, Orbitron, Segoe UI, sans-serif`.
- For PNG export, use any vector tool (Figma/Sketch/Inkscape) at 2x/4x.
